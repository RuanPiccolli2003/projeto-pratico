Informações sobre o versionamento semantico


O que é

- Também conhecido como SemVer é utilizando no GIT para
padronizar a numeração de versões para seguir o padrão
MAJOR.MINOR.PATCH Assim como: 1.0.0


Significado de MAJOR.MINOR.PATCH


- É a tradução dos tres algarismos no padrão SemVer
O MAJOR refere-se a alterações que podem ter grande quebra
de compatibilidade. O MINOR refere-se a adição de funções 
mantendo a compatiblidade. A PATCH refere-se a correção 
de BUGS e afins.

Momento em que deve-se utilizar cada um dos tipos de versão 

- PATCH: Utiliza-se quando são feitas correções de BUGS

- MINOR: Quando novas funcionalidades são realizadas

- MAJOR: Remoção ou adição de recursos existentes
